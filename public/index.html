DEĞİŞKENLER:
- t: 0'dan 1'e giden animasyon ilerlemesi
- W: sahne genişliği (piksel)
- H: sahne yüksekliği (piksel)

TEMEL ÇİZİM:
- arkaplan(renk)
- daire(x, y, r, renk)
- dikdortgen(x, y, w, h, renk)
- yazi(metin, x, y, boyut, renk)
- cizgi(x1, y1, x2, y2, renk, kalinlik)

ŞEKİLLER:
- yildiz(x, y, r, noktaSayisi, renk)
- kalp(x, y, boyut, renk)
- ucgen(x1, y1, x2, y2, x3, y3, renk)
- ok(x1, y1, x2, y2, renk, kalinlik)
- cokgen(x, y, yaricap, kenarSayisi, renk)
- yildizPatlamasi(x, y, boyut, renk)
- konfeti(x, y, sayi, boyut)
- simsek(x1, y1, x2, y2, renk, kalinlik)
- bulut(x, y, boyut, renk)
- gunes(x, y, yaricap, renk)

SESLENDİRME (TTS):
- seslendir("Metin", "tr")
- Belirtilen metni sese cevirir ve videoya gomer
- yazi() SESSIZDIR, sadece goruntu verir
- Diller: tr, en, de, fr, es, it, ru, ar, ja, ko, zh
- Metin 200 karakteri gecmesin

  ORNEK:
  @5s
  arkaplan('#0f1117');
  seslendir('Merhaba dunya!', 'tr');
  yazi('Merhaba dunya!', W/2, H/2, 80, '#fff');

MEDYA - EMOJI:
- emoji("🚀", x, y, boyut)

MEDYA - RESIM:
- resim(url, x, y, w, h)
- URL CORS desteklemeli (imgur, i.ibb.co, cloudinary)
- Ornek: resim('https://i.ibb.co/JjPFLbcP/Os-Code-Video.png', W/2 - 150, H/2 - 150, 300, 300);

YAZI ANIMASYONLARI:
- daktilo(metin, x, y, boyut, renk)
- kaydir(metin, x, y, boyut, renk)
- yukariCik(metin, x, y, boyut, renk)

EFEKT:
- gradient(renk1, renk2, "dikey"|"yatay"|"capraz")
- golge(renk, blur, xOffset, yOffset)
- golgeKapat()
- bulanikla(piksel)
- siyahBeyaz()
- sepya()
- filtreKapat()
- parcacik(x, y, sayi, renk, boyut)
- titre(miktar)

RENK PALETLERI (array doner):
- renk("neon") renk("gunbatimi") renk("okyanus")
- renk("ates") renk("orman") renk("pastel")
- renk("gece") renk("altin")
Kullanim: const p = renk("neon"); daire(100, 100, 50, p[0]);

KURALLAR:
- En uste sure yaz: @5s (max @60s)
- Coklu sahne icin --- satiri ile bol
- Sadece verilen fonksiyonlari kullan
- Renkleri hex ('#ff6b35') yaz
- Metin ortalama icin x = W/2, y = H/2 kullan
- Resim URL'si MUTLAKA CORS desteklemeli
- Seslendirme metni kisa olsun

ORNEK - Basit:
@5s
gradient('#0a0a1a', '#1a0033', 'dikey');
const x = 100 + t * (W - 200);
daire(x, H/2, 50, '#ff6b35');

@6s
